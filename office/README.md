# Пиксельный офис

Главная страница сайта: резюме в виде пиксельного офиса. Разделы резюме — предметы офиса (витрина, диплом, книжный
шкаф, глобус, игровой автомат…), агенты — костюмированные осьминожки, у каждого своя роль. Есть режим 2.5D — прогулка
по офису за Отто. Классическая версия резюме — [`/resume/old/`](https://akonyaev-ru.github.io/resume/old/).

## Сборка

Страница собирается в один файл: все скрипты, стили, шрифты и портрет вшиваются внутрь.

    python office/pix/build_demo.py --prod office/dist/index.html

На сайт её кладёт `tools/build_site.py` (в корень, рядом — `og.jpg` для превью ссылки). Без `--prod` получается
демо-версия с панелью переключателей (`office/dist/office_demo.html`).

## Что где

| Файл | Что это |
|---|---|
| `greybox.html` | страница офиса: разметка, стили, логика (план, агенты, окна разделов, телефон) |
| `pix/objects.js` | рисунки предметов офиса — сгенерированы `pix/objects.py`, руками не правятся |
| `pix/agents.js` | кадры агентов (костюмы из каталога `octopus/`) — сгенерированы `pix/agents.py` |
| `pix/pix.js`, `pix/rooms.js` | рисовальщик офиса на холсте: пол, стены, предметы |
| `pix/office3d.js` | режим 2.5D (WebGL2) |
| `pix/field.js`, `pix/drift.js` | фон — поле знаков и плывущие рисунки из знаков |
| `art/work/t16/art.js`, `art/work/plan.json`, `art/work/a/objects.json` | расстановка предметов (места и размеры) |
| `windows/` | окна разделов, клавиши тетриса, телефонный вид, пиксельный шрифт Press Start 2P |
| `octopus/` | каталог костюмов (`manifest.json`, `v2/`, `v3/`, `v5/`) и его генераторы `make_octopus*.py` |

Генераторы (`pix/objects.py`, `pix/agents.py`, `octopus/make_octopus*.py`) запускаются Python 3 и требуют Pillow.
